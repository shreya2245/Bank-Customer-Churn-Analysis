# Bank-Customer-Churn-Analysis
Customer Churn Analysis – End-to-End Power BI Project

This project performs a comprehensive analysis of customer churn using a real-world service dataset. Built entirely in Power BI, the analysis covers data cleaning, model building, visualization and insights generation.

# Project Overview
- Analyzed a customer dataset to identify churn behavior using Power BI.  
- Cleaned and modeled data in Power BI / Power Query.  
- Created calculated metrics using DAX (such as Churn Rate, Tenure, and Customer Status).  
- Developed an interactive dashboard that allows filtering by demographic and behavioral factors.

# Key Objectives
- Customers with shorter tenure are more likely to churn.  
- High churn risk among customers with fewer products or services.  
- Certain age or demographic groups might show different churn behavior.  
- Active monitoring of behavior metrics (balance, usage) helps identify signals before churn.

# Tools & Technologies:
- Power BI Desktop
- Power Query (for ETL/data preparation)
- DAX (for calculations and metrics) 

# Insights
- Dataset size: ~10,000 customers  
- Churned customers: ~2,037 → ~20.4% churn rate  
- Churn risk ↑ when: low credit score, low balance, one product only  
- Active members & multi–product customers show lower churn  
- Age 45-60 & certain geographies stand out for higher exit rates

# Conclusion
This customer churn analysis project provides clear visibility into why customers leave and which segments are at the highest risk. By using Power BI for data modeling, DAX calculations, and interactive visualizations, the project highlights key churn drivers such as low tenure, limited product usage, and behavioral patterns.
